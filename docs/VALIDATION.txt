KpPhageClassifier 0.1.2 release validation
========================================
Local checks performed on 18 November 2026, Linux, Python 3.13.

SOFTWARE AND INSTALLATION
-------------------------
28 unit/regression tests pass. Coverage includes per-genome reciprocal matching,
family ambiguity, order orientation/start invariance, rearrangements, evidence
thresholds, paralog/MTase exclusion, input IDs/coordinates, existing-output
preservation, installer integrity and transfer recovery, portable paths, packaged
release metadata and optional gene-caller checks.

A fresh virtual environment installed the package and DNA prediction dependencies.
The packaged CLI ran outside the source checkout. The wheel includes both the
reference-release registry and prediction helper. Source and wheel metadata pass
build/Twine checks; Ruff's F and E9 checks pass. Dependency checks found no conflicts.
The offline installer verified the real pinned release archive and installed it
successfully into a path containing spaces. A previous live Figshare download
was also verified and was used for the full classification run below.

GENE CALLING AND FULL CLASSIFICATION
-----------------------------------
The packaged Pyrodigal-gv helper produced identical normalized protein sequences
and gene coordinates to the original Pharokka-based helper for three references.
Raw prediction files differ only in internal sequence counters, which do not
change protein sequences, coordinates or downstream identifiers.

A full DNA -> prediction -> real bidirectional MMseqs2 -> assignment run used
Pyrodigal-gv 0.3.2, Pyrodigal 3.7.1 and MMseqs2 18.8cc5c. G0053, G0524 and G0119
were held out of scoring, family assignment and order comparisons:
  OQ830459.1: W005 / W005-S02; wGRR 0.890482
  MK422451.1: W020 / W020-S01; wGRR 0.826011
  LN866626.1: W001 / W001-S05; wGRR 0.935410
  N_ONLY_CONTROL: unassigned / unassigned; wGRR 0.000000

All computed assignment fields match the previous validated run. The previous run
explicitly labelled input completeness as complete; this run used the default
unknown. This user-supplied field differs; the inferred results do not.
Per-reference similarities,
family assignments, gene-order comparisons, normalized proteins and coordinates
are unchanged. The N-only control is unassigned with no predicted proteins.
Reference core-file hashes were checked and remain unchanged.

SCOPE
-----
These are engineering checks with known reference genomes. Original family
construction retained the held-out sequences; these checks are not independent
biological validation or calibrated accuracy estimates. Linux/Python 3.13 was
tested locally. After upload, the GitHub test and packaging matrix passed on
Python 3.10, 3.11, 3.12 and 3.13:
https://github.com/lxd98/KpPhageClassifier/actions/runs/44263954708
A new conda solve, macOS and Windows/WSL were not tested locally.
